# Wind L1 raw files

Place monthly ASCII responses from `https://wind.nasa.gov/mfi_swe_display_results.php` in `MFI/` and `SWE/`. MFI uses GSM magnetic fields (`b,bx,by,bz`); SWE uses plasma and derived parameters (`v,np,psw,ma,mms,epsilon,vbs`, etc.). The downloader creates these files automatically. Do not commit them.
